My [bachelor thesis](https://drive.google.com/file/d/1ORBefG_7pYTAcOtzEbaA5s2RVjvB2m2V/view), shown live at Japan IT Week.
- **[EraseAll](https://github.com/Holo911/EraseAll)**: removes people and objects from photos and rebuilds what was behind them. Runs offline on an ordinary laptop CPU.

- **[BIOS-update](https://github.com/Holo911/BIOS-update)**: a BIOS flashing tool in C that starts the flasher with `fork()`/`execvp()` instead of a shell, so there is nothing to inject into.
